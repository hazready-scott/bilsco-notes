# Hello World

This is the first note published from my Obsidian vault to
[notes.bilsco.ca](https://notes.bilsco.ca).

The pipeline: a note dropped into the vault's `Public/` folder is picked up by
a sync script (with a deny-list backstop so private material can never leak),
pushed to a Git repository, and rebuilt into this site automatically by
Cloudflare Pages.

If you can read this, the whole chain works.
